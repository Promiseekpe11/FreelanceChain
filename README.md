# FreelanceChain

A decentralized freelance marketplace connecting skilled professionals with clients for project-based work on Stacks blockchain.

## Features

- Freelancer profile registration with skill categorization
- Hourly rate-based hiring system with instant payments
- Platform manager verification for quality assurance
- Contract tracking and project scope management
- Transparent marketplace for professional services

## Smart Contract Functions

### Public Functions
- `register-freelancer` - Register as a freelancer with skills and rates
- `hire-freelancer` - Hire a freelancer for project work
- `verify-freelancer` - Verify freelancer credentials (manager only)

### Read-Only Functions
- `get-freelancer` - Get freelancer profile details
- `get-contract-record` - Get specific contract information
- `get-contract-count` - Get total contracts for freelancer
- `get-platform-stats` - Get platform statistics

## Usage

Deploy the contract to create a decentralized freelance marketplace where professionals can offer their services and clients can hire them with transparent, blockchain-verified transactions.
